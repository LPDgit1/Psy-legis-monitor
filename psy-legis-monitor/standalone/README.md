# Standalone locale

Fare doppio clic su `open-standalone.cmd` per aprire una versione locale e leggera
della dashboard nel browser. Non richiede Python, Streamlit, Node o una connessione
di rete.

La versione standalone usa dati dimostrativi e non esegue il recupero live delle fonti.
I link alla fonte ufficiale restano disponibili per la verifica.
